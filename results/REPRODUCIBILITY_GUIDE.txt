================================================================================
SCRIPT STRUCTURE
================================================================================

The experiment_crosssource_seeding.py script contains:

1. load_data()
   - Loads full_pipeline_per_sample.csv (10,958 samples)
   - Loads unified_dataset.csv for source information
   - Returns merged DataFrame with all predictions and source labels

2. bootstrap_ci(y_true, y_pred, metric_func, n_iterations=500, ci=95)
   - Computes bootstrap confidence intervals for metrics
   - Performs 500 iterations of resampling with replacement
   - Returns mean, lower bound, upper bound

3. compute_metrics(y_true, y_pred)
   - Computes F1, Precision, Recall, Accuracy
   - Returns dict of metrics

4. simulate_cross_source_pred(row)
   - Simulates prediction for cross-source seeding scenario
   - Uses Stage 4 (LLM) as base
   - Applies Stage 1 overrides for high-confidence detections (>=0.90)

5. run_experiment(merged_df)
   - Main experiment logic
   - Compares 3 conditions:
     a) Stage 4 baseline
     b) Cross-source simulation
     c) Same-source full pipeline
   - Computes contamination effect and CIs
   - Returns comprehensive results dictionary

6. main()
   - Orchestrates loading, running, and saving

================================================================================
STATISTICAL RIGOR
================================================================================

Bootstrap Method:
  • 500 iterations provides stable CI estimates
  • Percentile-based CI: [2.5%, 97.5%] percentiles of bootstrap distribution
  • Random seed 42 ensures reproducibility
  • No distributional assumptions (non-parametric)

Confidence Level:
  • 95% CI is standard in ML research
  • CI excludes zero → p-value < 0.05
  • Large sample size (10,137) → narrow CI bounds

Assumptions Validated:
  • Stage 1 independence: ✓ (heuristic rules, not learned)
  • Stage 4 independence: ✓ (LLM judge, not trained on memory)
  • Stage 2 seeding-sensitivity: ✓ (empirically demonstrated)

================================================================================
TROUBLESHOOTING
================================================================================

Q: Script doesn't find data files
A: Ensure you're running from repo root or update REPO path in script

Q: Different CI bounds than reported
A: Verify sklearn version (metrics.f1_score behavior may vary)
   Use random seed 42 for reproducibility

Q: Memory errors on large bootstrap
A: Reduce n_iterations from 500 to 100 (faster, wider CI)
   Or use stratified sampling instead of uniform resampling

Q: Want different evaluation set
A: Modify line: safeguard_df = merged_df[merged_df['source'] == 'hf_safeguard_prompt_injection']
   Change to: deepset_df = merged_df[merged_df['source'] == 'hf_deepset_prompt_injections']
